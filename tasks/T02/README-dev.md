# T02. Скрытая записка

**Тема:** файловая система, скрытые файлы · **Сложность:** 🟢 · **Время:** 3–5 минут

## Условие для студента

> В домашнем каталоге пользователя лежит записка с флагом.
>
> Обычный просмотр каталога её не показывает.
>
> Найдите файл с флагом и прочитайте его.

Имя файла и точный путь не сообщаются.

## Состояние контейнера

```text
/home/ctf/
├── Documents/
│   ├── report.txt
│   ├── todo.txt
│   └── .secret        <- здесь флаг (скрытый файл)
├── Downloads/
│   └── manual.txt
└── notes.txt
```

Пользователь: `ctf`, cwd: `/home/ctf`.

## Флаг

```text
flag{hidden_note}
```

Переопределяется переменной `TASK_FLAG`.

## Ожидаемые навыки

`ls`, `ls -a`, `cat`.

## Подсказки

1. Обычный `ls` не показывает файлы, имя которых начинается с точки.
2. Посмотрите содержимое каталога вместе со скрытыми файлами и
   загляните в подкаталоги.
3. Флаг — это строка вида `flag{...}` внутри текстового файла.

## Решение

```bash
cd ~/Documents
ls -a
cat .secret
```

## Smoke test

```bash
docker run --rm linux-ctf/t02 id -u
docker run --rm linux-ctf/t02 bash -c 'test -f /home/ctf/Documents/.secret'
docker run --rm linux-ctf/t02 grep -q 'flag{' /home/ctf/Documents/.secret
```

Проверяется: пользователь `ctf` существует, скрытый файл с флагом
лежит в `Documents/.secret`.
