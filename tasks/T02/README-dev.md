# T02. Скрытая записка

**Тема:** файловая система, скрытые файлы · **Сложность:** 🟢 · **Время:** 3–5 минут

## Условие для студента

> В домашнем каталоге пользователя лежит записка с ключом.
>
> Обычный просмотр каталога её не показывает.
>
> Найдите скрытый файл, прочитайте ключ (это hex-строка из 32 символов),
> а затем расшифруйте флаг:
>
> ```bash
> cd /home/ctf
> ./decrypt.sh <ключ>
> ```

Имя скрытого файла и точный путь не сообщаются.

## Состояние контейнера

```text
/home/ctf/
├── Documents/
│   ├── .secret        <- здесь ключ (скрытый файл)
│   ├── report.txt
│   └── todo.txt
├── Downloads/
│   └── manual.txt
├── flag.enc           <- зашифрованный флаг
├── decrypt.sh         <- ./decrypt.sh <ключ>
├── README
└── notes.txt
```

Пользователь: `ctf`, cwd: `/home/ctf`.

## Флаг

```text
SSL{hidden_note}
```

Флаг хранится в `flag.enc` в зашифрованном виде и становится виден
только после `./decrypt.sh <ключ>`.  Открытым текстом в образе его нет.

## Ожидаемые навыки

`ls`, `ls -a`, `cat`.

## Подсказки

1. Обычный `ls` не показывает файлы, имя которых начинается с точки.
2. Посмотрите содержимое каталога вместе со скрытыми файлами
   (`ls -a`) и загляните в подкаталоги.
3. Ключ — это строка из 32 шестнадцатеричных цифр (`0-9`, `a-f`)
   внутри найденного файла.

## Решение

```bash
cd ~/Documents
ls -a                 # видим скрытый .secret
cat .secret           # находим ключ (hex, 32 символа)
cd /home/ctf
./decrypt.sh <ключ>   # печатает SSL{hidden_note}
```

## Smoke test

```bash
# скрытый файл на месте
docker run --rm linux-ctf/t02 bash -c 'test -f /home/ctf/Documents/.secret'

# в образе нет открытого флага
docker run --rm linux-ctf/t02 bash -c \
  '! grep -rq "SSL{" /home /opt /etc /usr 2>/dev/null'

# ключ находится и расшифровывает флаг
docker run --rm linux-ctf/t02 bash -c \
  'cd /home/ctf && ./decrypt.sh \
     "$(grep -oE "^[0-9a-f]{32}$" Documents/.secret)"' \
  | grep -qx 'SSL{hidden_note}'
```

Проверяется: пользователь `ctf` существует, скрытый файл с ключом лежит
в `Documents/.secret`, открытого флага в образе нет, а `./decrypt.sh`
с найденным ключом печатает `SSL{hidden_note}`.
