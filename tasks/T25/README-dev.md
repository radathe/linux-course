# T25. Неправильный заголовок

**Тема:** HTTP-заголовки · **Сложность:** 🟢 · **Время:** 5–7 минут

## Условие для студента

> Внутри контейнера на локальном адресе запущен веб-сервис со
> страницей администратора.
>
> Обычный запрос к ней отклоняется — сервер ожидает специальный
> заголовок запроса.  Разберитесь, какой именно, и получите флаг.

Имя заголовка, его значение и точный путь в условии напрямую не
сообщаются, но их можно узнать из ответов сервера.

## Состояние контейнера

```text
/home/ctf/README.txt   <- подсказка про сервис
127.0.0.1:8080         <- HTTP-сервис (слушает только localhost)
/opt/server.py         <- исходник сервиса
/var/log/task.log      <- лог сервиса
```

Пользователь: `ctf`, cwd: `/home/ctf`.

Страница администратора — `/admin`.  Без нужного заголовка сервер
возвращает `403 Forbidden` и в самом ответе подсказывает имя нужного
заголовка и его значение.

## Флаг

```text
flag{custom_headers}
```

Передаётся сервису через переменную `TASK_FLAG`.

## Ожидаемые навыки

`curl`, чтение заголовков ответа (`-i`, `-v`), передача собственного
заголовка запроса (`-H`), различение заголовков запроса и ответа.

## Подсказки

1. Осмотритесь: в домашнем каталоге есть подсказка.
2. Определите, на каком локальном порту слушает сервис.
3. Запросите страницу администратора и посмотрите полный ответ
   вместе с заголовками.
4. В ответе `403` присутствует заголовок-подсказка: из него видно
   имя нужного заголовка и требуемое значение.
5. Повторите запрос, добавив к нему этот заголовок с указанным
   значением.
6. Сравните: без заголовка — `403`, с правильным заголовком — флаг.

## Решение

```bash
cat README.txt
curl -i http://127.0.0.1:8080/admin
# В ответе: HTTP/1.1 403 ... и заголовок X-CTF-Hint: use-the-header

curl -i -H 'X-CTF-Hint: use-the-header' http://127.0.0.1:8080/admin
```

Ожидаемый ответ:

```text
flag{custom_headers}
```

## Smoke test

```bash
docker run --rm linux-ctf/t25 bash -c \
  'python3 - <<PY
import urllib.request
req = urllib.request.Request("http://127.0.0.1:8080/admin",
                             headers={"X-CTF-Hint": "use-the-header"})
print(urllib.request.urlopen(req).read().decode())
PY'
```

Проверяется: контейнер стартует, сервис слушает `127.0.0.1:8080`,
`/admin` без заголовка отвечает `403` с заголовком-подсказкой, а с
правильным заголовком отдаёт флаг.
