# T01. Осмотр комнаты

**Тема:** файловая система · **Сложность:** 🟢 · **Время:** 5–8 минут

## Условие для студента

> Вы впервые подключились к Linux-машине.
>
> Настоящий флаг зашифрован и лежит в файле `flag.enc` в вашем домашнем
> каталоге.  Чтобы его получить, нужно найти **ключ** (случайную
> hex-строку), спрятанный где-то в каталогах пользователя, и выполнить
> `./decrypt.sh <ключ>`.
>
> Найдите ключ и получите флаг.

Точный путь к ключу не сообщается.

## Состояние контейнера

```text
/home/ctf/
├── Documents/
│   ├── welcome.txt
│   └── notes.txt        <- здесь ключ
├── Downloads/
│   └── image.txt
├── flag.enc             <- зашифрованный флаг
├── decrypt.sh           <- расшифровка: ./decrypt.sh <ключ>
├── README
└── readme.txt
```

Пользователь: `ctf`, cwd: `/home/ctf`.  Состояние готовится на этапе
сборки; внутри контейнера нет скрипта инициализации.

## Флаг

```text
SSL{first_linux_steps}
```

В образе флаг лежит только зашифрованным (`flag.enc`), открытый текст
нигде не хранится.

## Ожидаемые навыки

`pwd`, `ls`, `cd`, `cat`.

## Подсказки

1. Сначала определите, где вы находитесь, и посмотрите содержимое
   каталога.
2. Загляните в подкаталоги `Documents` и `Downloads`.
3. Ключ — это случайная hex-строка (32 символа).  Найдя её, выполните
   `./decrypt.sh <ключ>`.

## Решение

```bash
pwd
ls
cd Documents
ls
cat notes.txt            # ... <ключ>
cd ~
./decrypt.sh <ключ>
# SSL{first_linux_steps}
```

## Smoke test

```bash
docker run --rm linux-ctf/t01 bash -c \
  'test -z "$(grep -rl "SSL{" /home /opt /etc /usr 2>/dev/null)" && test ! -e /opt/setup.sh'
docker run --rm linux-ctf/t01 bash -c \
  'key=$(grep -oE "[0-9a-f]{32}" /home/ctf/Documents/notes.txt | head -1); cd /home/ctf && ./decrypt.sh "$key"'
```

Проверяется: открытого флага и setup-скрипта в образе нет; ключ лежит в
`Documents/notes.txt`; расшифровка даёт флаг.
