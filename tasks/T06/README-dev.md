# T06. Лишние данные

**Тема:** обработка текста конвейером · **Сложность:** 🟡 · **Время:** 5–8 минут

## Условие для студента

> В файле `users.txt` каждая строка имеет вид `имя:роль`, причём часть
> имён повторяется.
>
> Получите отсортированный список **уникальных** имён пользователей
> (без ролей).
>
> Среди имён спрятан флаг.

## Состояние контейнера

```text
/home/ctf/
└── users.txt          <- строки "имя:роль", имена повторяются
```

Пользователь: `ctf`, cwd: `/home/ctf`.
Одно из имён — это строка флага.

## Флаг

```text
flag{text_pipeline}
```

Переопределяется переменной `TASK_FLAG`.

## Ожидаемые навыки

`cut`, `sort`, `uniq`, конвейер (`|`).

## Подсказки

1. Имя и роль разделены двоеточием — отделить первое поле поможет
   `cut -d: -f1`.
2. Чтобы убрать повторы, список нужно сначала отсортировать, а затем
   пропустить через `uniq`.
3. Проверить итог можно командой `sort -u`, а флаг — поиском строки
   вида `flag{...}` в результате.

## Решение

```bash
cut -d: -f1 users.txt | sort | uniq
```

Короткий эквивалент:

```bash
cut -d: -f1 users.txt | sort -u
```

В итоговом списке видно имя `flag{text_pipeline}`.

## Smoke test

```bash
docker run --rm linux-ctf/t06 id -u
docker run --rm linux-ctf/t06 test -f /home/ctf/users.txt
docker run --rm linux-ctf/t06 bash -c "cut -d: -f1 /home/ctf/users.txt | sort -u | grep -q 'flag{'"
```

Проверяется: файл существует, после `cut | sort -u` флаг остаётся в
списке имён.
