# T22. Обработай поток

**Тема:** конвейеры, grep, sort, uniq · **Сложность:** 🟢 · **Время:** 5–8 минут

## Условие для студента

> Программа `/opt/log-generator` печатает большой журнальный поток.
> Среди строк со значениями `TOKEN=...` спрятан флаг.
>
> Найдите его, не читая весь вывод глазами.

## Состояние контейнера

```text
/opt/log-generator   <- исполняемый скрипт (0755, ctf:ctf)
```

Скрипт печатает поток строк вида `INFO ...`, `DEBUG ...` и
`TOKEN=...`.  Большинство значений `TOKEN=` повторяются, но несколько
встречаются ровно один раз — в том числе флаг.

## Флаг

```text
flag{stream_processing}
```

Переопределяется переменной `TASK_FLAG`.

## Ожидаемые навыки

Конвейеры (`|`), фильтрация (`grep`), сортировка (`sort`) и поиск
уникальных строк (`uniq`, `uniq -u`, `uniq -c`).

## Подсказки

1. Весь вывод читать не нужно: отфильтруйте строки, содержащие
   `TOKEN=`.
2. Чтобы найти строки, которые встречаются один раз, сначала
   отсортируйте их, а затем примените `uniq -u` (или `uniq -c`).
3. Флаг имеет вид `flag{...}` — его можно найти и простым `grep`.

## Решение

```bash
# Отфильтровать токены, отсортировать и убрать повторы:
/opt/log-generator | grep TOKEN= | sort | uniq

# Либо сразу оставить только уникальные строки:
/opt/log-generator | grep TOKEN= | sort | uniq -u

# Или найти флаг по префиксу:
/opt/log-generator | grep -o 'flag{[^}]*}'
```

## Smoke test

```bash
docker run --rm linux-ctf/t22 test -x /opt/log-generator
docker run --rm linux-ctf/t22 bash -c '/opt/log-generator | grep -q "TOKEN="'
docker run --rm linux-ctf/t22 bash -c '/opt/log-generator | grep TOKEN= | grep -q "flag{"'
```

Проверяется: `/opt/log-generator` исполняем и печатает поток с токенами,
среди которых есть флаг.
