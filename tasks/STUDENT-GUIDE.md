# Практикум Linux/CTF — инструкция студенту

Эта инструкция описывает, как загрузить готовые образы задач и запустить их
в терминале.  Знание Docker для решения задач **не требуется**: нужно лишь
выполнить несколько команд ниже.

## Что вам выдано

Файлы образов вида:

```text
linux-ctf-t01.tar
linux-ctf-t02.tar
...
linux-ctf-t15.tar
```

Каждый `.tar` — это сохранённый Docker-образ с одной задачей.  Задачи идут
по возрастанию сложности:

| ID  | Название              | Тема                    |
|-----|-----------------------|-------------------------|
| T01 | Осмотр комнаты        | файловая система        |
| T02 | Скрытая записка       | скрытые файлы           |
| T03 | Запутанный путь       | пути, `.` и `..`        |
| T04 | Нужная строка         | grep                    |
| T05 | Большой журнал        | grep -n                 |
| T06 | Лишние данные         | cut / sort / uniq       |
| T07 | Где лежит флаг?       | find                    |
| T08 | Чужой файл            | группы и права          |
| T09 | Запусти программу     | chmod, бит `x`          |
| T10 | Что внутри?           | zip                     |
| T11 | Испорченное сообщение | распознавание base64    |
| T12 | Что это вообще?       | file, strings           |
| T13 | Странная программа    | strings + запуск        |
| T14 | Что здесь работает?   | процессы и аргументы    |
| T15 | Где настоящий вывод?   | stdout / stderr         |

Формат флага — `SSL{...}`.  Флаг в каждой задаче зашифрован: сначала нужно
найти ключ (об этом сказано в условии и в файле `README` в домашнем
каталоге), а затем выполнить `./decrypt.sh <ключ>`.

## Что нужно установить

Docker:

* Linux — `docker` + запущенный демон `dockerd`;
* Windows / macOS — Docker Desktop.

Проверка, что всё работает:

```bash
docker version
```

Если команда отвечает ошибкой подключения к демону — сначала запустите
Docker (Docker Desktop или `sudo systemctl start docker`).

## Шаг 1. Загрузить образ

Загрузите образ нужной задачи:

```bash
docker load -i linux-ctf-t01.tar
```

В ответ Docker напечатает что-то вроде:

```text
Loaded image: linux-ctf/t01:latest
```

Загрузить сразу все образы из текущего каталога:

```bash
for f in linux-ctf-t*.tar; do docker load -i "$f"; done
```

Проверить, что образы появились в списке:

```bash
docker images
```

В списке должны быть строки `linux-ctf/t01` … `linux-ctf/t15`.

## Шаг 2. Запустить задачу

```bash
docker run --rm -it linux-ctf/t01
```

Разбор ключей:

* `--rm` — автоматически удалить контейнер после выхода;
* `-it` — интерактивный терминал (без него shell не откроется).

После запуска вы окажетесь в командной строке пользователя `ctf` в рабочем
каталоге задачи (обычно `/home/ctf`).  Дальше решайте задачу обычными
командами Linux.

Рекомендуемые ограничения ресурсов и отключение сети (нужен только
`localhost`):

```bash
docker run --rm -it \
    --memory=256m --cpus=0.5 \
    --network=none \
    linux-ctf/t01
```

## Шаг 3. Выйти из задачи

```bash
exit
```

или нажмите `Ctrl+D`.

## Перезапуск и сброс состояния

**Каждый запуск `docker run` создаёт новый контейнер с чистым состоянием.**
Если что-то испортили — просто выйдите и запустите задачу снова.

Если запускали контейнер без `--rm` (например, в фоне), посмотрите и
удалите его вручную:

```bash
docker ps -a          # список всех контейнеров
docker rm <id-или-имя>
```

## Полезные команды Docker

```bash
docker load -i FILE.tar        # загрузить образ из файла
docker images                  # список образов
docker run --rm -it IMAGE      # запустить задачу
docker ps                      # запущенные контейнеры
docker ps -a                   # все контейнеры
docker rm ID                   # удалить контейнер
docker rmi linux-ctf/t01       # удалить образ
docker system df               # сколько места занято
docker system prune            # очистить неиспользуемое
```

Запустить команду в задаче, не открывая shell (для быстрой проверки):

```bash
docker run --rm linux-ctf/t01 ls /home/ctf
```

## Как сдать флаг

Найденный флаг вида `SSL{...}` вводится на платформе/передаётся
преподавателю — в зависимости от того, как организован курс.  Сам флаг
в контейнере ничего не «отправляет».

## Частые проблемы

| Симптом | Что делать |
|---------|-----------|
| `Cannot connect to the Docker daemon` | Запустите Docker (Docker Desktop или `sudo systemctl start docker`). |
| `permission denied` при вызове `docker` | Добавьте пользователя в группу `docker`: `sudo usermod -aG docker $USER`, затем перелогиньтесь. Либо используйте `sudo`. |
| `docker load`: `no space left on device` | Освободите место: `docker system prune -a`. |
| `docker load`: `open ...: no such file` | Проверьте имя файла и что вы в каталоге с `.tar` (`ls`). |
| В терминале «кракозябры» вместо русских букв | Запустите с `-e LANG=C.UTF-8`: `docker run --rm -it -e LANG=C.UTF-8 linux-ctf/t01`. |
| Shell сразу закрывается | Не забудьте ключ `-it` (интерактивный терминал). |
| Порт «занят» или сеть недоступна | Сетевые задачи в этом наборе отсутствуют: используйте `--network=none`. |

## Приложение для преподавателя: подготовка образов

Собрать образы и сохранить их в `.tar` для раздачи студентам:

```bash
cd tasks
make all

mkdir -p dist
for t in $(seq -w 1 15); do
    docker save "linux-ctf/t${t}:latest" -o "dist/linux-ctf-t${t}.tar"
done

( cd dist && sha256sum linux-ctf-t*.tar > SHA256SUMS )
```

Готовые архивы и контрольные суммы складываются в `tasks/dist/`
(каталог исключён из git).  Раздайте студентам `.tar`-файлы оттуда.
