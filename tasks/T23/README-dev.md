# T23. Подключись к сервису

**Тема:** сетевые сервисы, netcat · **Сложность:** 🟢 · **Время:** 5–8 минут

## Условие для студента

> Внутри машины на порту `31337` работает сетевой сервис.
>
> Подключитесь к нему и получите флаг.

## Состояние контейнера

```text
/opt/server.py        <- TCP-сервер (127.0.0.1:31337), запускается
                         в фоне из start-services.sh
```

Сервис слушает только `127.0.0.1`, поэтому доступен лишь изнутри
контейнера.  При подключении он приветствует клиента и отправляет флаг,
после чего закрывает соединение; цикл `accept` позволяет подключаться
сколько угодно раз.

## Флаг

```text
flag{netcat_basics}
```

Переопределяется переменной `TASK_FLAG` и передаётся серверу через
окружение.

## Ожидаемые навыки

`netcat` (`nc`), работа с TCP-портами, `ss`/`netstat`.

## Подсказки

1. Сначала проверьте, какие порты слушаются: `ss -ltnp` (или
   `netstat -ltnp`).
2. Для подключения к TCP-сервису удобно использовать `nc`:
   `nc 127.0.0.1 31337`.
3. Сервис отдаёт всё сразу и закрывает соединение — просто прочитайте
   ответ.  Если ответ не появился, нажмите Enter.

## Решение

```bash
# Посмотреть открытые порты:
ss -ltn

# Подключиться и получить флаг:
nc 127.0.0.1 31337
```

Ожидаемый вывод:

```text
Welcome!
flag{netcat_basics}
```

## Smoke test

```bash
docker run -d --rm --name t23 linux-ctf/t23 sleep infinity
docker exec t23 bash -c 'timeout 3 bash -c "cat < /dev/tcp/127.0.0.1/31337" | grep -q "flag{"'
docker rm -f t23
```

Проверяется: сервис слушает `127.0.0.1:31337` и при подключении отдаёт
флаг.
