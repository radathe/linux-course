# T24. Исследуй веб-сервис

**Тема:** веб-сервисы внутри контейнера · **Сложность:** 🟢 · **Время:** 5–7 минут

## Условие для студента

> Внутри контейнера на локальном адресе запущен небольшой веб-сервис.
>
> Он отдаёт разные ответы по разным путям, а один из путей открывает
> флаг.
>
> Исследуйте сервис и получите флаг.

Точный адрес, порт и имена путей в условии не сообщаются — их нужно
найти осмотрев окружение и ответы сервиса.

## Состояние контейнера

```text
/home/ctf/README.txt   <- подсказка про сервис
127.0.0.1:8080         <- HTTP-сервис (слушает только localhost)
/opt/server.py         <- исходник сервиса
/var/log/task.log      <- лог сервиса
```

Пользователь: `ctf`, cwd: `/home/ctf`.

Сервис запускается из `start-services.sh` в фоне при старте контейнера.

## Флаг

```text
flag{curl_basics}
```

Передаётся сервису через переменную `TASK_FLAG` (значение по умолчанию
задано в `setup.sh`/`start-services.sh`).

## Ожидаемые навыки

`curl` (или `wget`), работа с HTTP-кодами и заголовком `Location`,
понятия «локальный адрес» и «порт».

## Подсказки

1. Осмотритесь в домашнем каталоге: там лежит подсказка.
2. Узнайте, какие порты слушаются на локальном интерфейсе.
3. Обратитесь к корню сервиса и посмотрите на код ответа: сервис
   перенаправляет на другой путь.
4. Перейдите по адресу из `Location` — сервис подскажет следующий путь.
5. Запросите подсказанный путь: там лежит флаг.
6. Если ответ «Not Found», проверьте точное написание пути.

## Решение

```bash
cat README.txt
ss -ltnp | grep 8080            # либо: netstat -ltnp
curl -i http://127.0.0.1:8080/  # 302, Location: /welcome
curl -i http://127.0.0.1:8080/welcome
curl http://127.0.0.1:8080/secret
```

Ожидаемый ответ последнего запроса:

```text
flag{curl_basics}
```

## Smoke test

```bash
docker run --rm linux-ctf/t24 bash -c \
  'python3 - <<PY
import urllib.request, urllib.error
req = urllib.request.Request("http://127.0.0.1:8080/")
try:
    urllib.request.urlopen(req)
except urllib.error.HTTPError as e:
    pass
print(urllib.request.urlopen("http://127.0.0.1:8080/secret").read().decode())
PY'
```

Проверяется: контейнер стартует, сервис слушает `127.0.0.1:8080`,
`/` отвечает перенаправлением, `/secret` отдаёт флаг.
