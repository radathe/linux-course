# T20. Секрет процесса

**Тема:** процессы и окружение, /proc · **Сложность:** 🟡 · **Время:** 7–10 минут

## Условие для студента

> В системе работает несколько процессов `worker`.
>
> У одного из них в окружении есть секрет — это флаг.
>
> Найдите процесс и прочитайте его переменные окружения.

## Состояние контейнера

```text
/opt/worker            <- ELF-пустышка: спит вечно и никогда не завершается
```

`start-services.sh` запускает от имени `ctf` четыре процесса `worker`:

* три процесса-приманки — без секрета;
* один процесс, которому через переменную окружения `SECRET` передаётся
  флаг.

Флаг не передаётся в аргументах (его нет в `cmdline`), не хранится в
файлах и отсутствует в готовом образе — он попадает только в окружение
процесса при запуске контейнера.

## Флаг

```text
flag{environment_secret}
```

Переопределяется переменной `TASK_FLAG`.

## Ожидаемые навыки

`ps`, `pgrep`, `/proc/<PID>/environ`, понимание окружения процесса и
прав доступа к `/proc`.

## Подсказки

1. Список процессов удобно смотреть командой `pgrep -a worker` или
   `ps aux | grep worker`.
2. Переменные окружения процесса лежат в `/proc/<PID>/environ`, но
   читать их может только владелец процесса — вот почему процессы
   запускаются от имени `ctf`.
3. Файл `/proc/<PID>/environ` разделён NUL-байтами: удобно вывести его
   через `tr '\0' '\n' < /proc/<PID>/environ` или `cat -v`.

## Решение

```bash
# Найти процессы worker:
pgrep -a worker

# Для каждого PID посмотреть окружение и найти SECRET:
for pid in $(pgrep -x worker); do
    echo "== PID $pid =="
    tr '\0' '\n' < "/proc/$pid/environ" | grep SECRET
done
```

У одного из процессов в выводе появится строка
`SECRET=flag{environment_secret}`.

## Smoke test

```bash
docker run --rm linux-ctf/t20 bash -c 'test -x /opt/worker'
docker run --rm linux-ctf/t20 bash -c 'pgrep -x worker >/dev/null'
docker run --rm linux-ctf/t20 bash -c \
  'for p in $(pgrep -x worker); do tr "\0" "\n" < /proc/$p/environ; done | grep -q "SECRET=flag{"'
```

Проверяется: `/opt/worker` исполняем, процессы `worker` запущены и у
одного из них в окружении есть `SECRET` с флагом.
