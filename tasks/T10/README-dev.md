# T10. Запусти программу

**Тема:** права на файл · **Сложность:** 🟢 · **Время:** 3–5 минут

## Условие для студента

> В каталоге `/opt` находится программа `runme`. Запустите её — она
> напечатает флаг.
>
> Программа принадлежит вам, но что-то мешает её запустить.

Имя программы известно.

## Состояние контейнера

```text
/opt/
└── runme   # ctf:ctf, права 644 (нет права на выполнение), печатает флаг
```

Пользователь: `ctf`, cwd: `/home/ctf`.

## Флаг

```text
flag{execution_permission}
```

Переопределяется переменной `TASK_FLAG`.

## Ожидаемые навыки

`ls -l`, `chmod u+x`, запуск скрипта `./runme`.

## Подсказки

1. Посмотрите на права: `ls -l /opt/runme`. Триада `644` не содержит
   `x` — бит выполнения снят.
2. Файл принадлежит вам, поэтому право можно выдать самому:
   `chmod u+x`. Указывать `sudo` не нужно.

## Решение

```bash
ls -l /opt/runme
chmod u+x /opt/runme
/opt/runme
```

## Smoke test

```bash
docker run --rm linux-ctf/t10 test -f /opt/runme
docker run --rm linux-ctf/t10 bash -c 'test -x /opt/runme && exit 1 || exit 0'
docker run --rm linux-ctf/t10 bash -c \
    'chmod u+x /opt/runme && /opt/runme | grep -q "flag{"'
```

Проверяется: файл существует, изначально **не** исполняем, права
владельца позволяют выдать бит `x`, после чего программа печатает флаг.
