# T18. Автоматизируй поиск

**Тема:** bash-скрипты, циклы и grep · **Сложность:** 🟡 · **Время:** 10–15 минут

## Условие для студента

> В каталоге `/opt/data` лежит сто текстовых файлов. Ровно в одном из
> них есть строка `TARGET` и рядом с ней — флаг.
>
> Просматривать сто файлов вручную долго, поэтому напишите скрипт,
> который сам перебирает файлы и находит тот, где встречается `TARGET`.
>
> Использовать рекурсивный поиск `grep -R` (и его аналоги вроде
> `grep -r`) запрещено. Нужен собственный перебор файлов в цикле.

Формат флага: `flag{...}`.

## Состояние контейнера

```text
/opt/data/
├── file_001.txt
├── file_002.txt
├── ...
└── file_100.txt       <- ровно в одном есть строка TARGET и флаг
```

Пользователь: `ctf`, cwd: `/home/ctf`. Каталог `/opt/data` доступен
только на чтение; файлы выбираются случайно при запуске контейнера.

## Флаг

```text
flag{automation}
```

Переопределяется переменной `TASK_FLAG` и записывается в один из
файлов в `setup.sh`.

## Ожидаемые навыки

`for` по маске файлов, `if`, `grep` по одному файлу, работа с
аргументами и переменными в bash.

## Подсказки

1. Переберите файлы маской: `for f in /opt/data/*; do ... done`.
2. Внутри цикла проверьте условие: `if grep -q TARGET "$f"; then ...`.
3. Результат проверки удобно сохранять в переменную или сразу выводить
   имя подходящего файла.

## Решение

Создайте скрипт `find_target.sh`:

```bash
#!/bin/bash
set -euo pipefail

for f in /opt/data/*; do
    if grep -q TARGET "$f"; then
        echo "Найдено: $f"
        cat "$f"
    fi
done
```

Запуск:

```bash
chmod +x find_target.sh
./find_target.sh
# ... flag{automation}
```

## Smoke test

```bash
docker run --rm linux-ctf/t18 sh -c 'test "$(ls /opt/data/*.txt | wc -l)" -eq 100'
docker run --rm linux-ctf/t18 sh -c 'test "$(grep -l TARGET /opt/data/*.txt | wc -l)" -eq 1'
docker run --rm linux-ctf/t18 sh -c 'grep -l TARGET /opt/data/*.txt | xargs grep -q "flag{"'
```

Проверяется: файлов ровно 100, строка `TARGET` встречается ровно в
одном файле, и в нём же лежит флаг.
