Переменные окружения

Каждый запущенный процесс в Linux получает окружение - набор переменных, содержащих различную информацию, доступную этому процессу. Такие переменные называются переменными окружения (environment variables).

Они используются для передачи настроек и другой информации программам. Например, благодаря переменной HOME программа может узнать домашний каталог пользователя, а PATH содержит список каталогов, в которых shell ищет исполняемые программы.



Просмотр переменных окружения

Посмотреть переменные окружения можно с помощью команды:

> env

Например:

USER=alice
HOME=/home/alice
PWD=/home/alice/ctf
PATH=/usr/local/bin:/usr/bin:/bin
SHELL=/bin/bash

Каждая строка имеет вид:

ИМЯ=ЗНАЧЕНИЕ

Посмотреть конкретную переменную можно с помощью echo:

> echo "$HOME"

Результат:

/home/alice

Другие распространённые переменные:

> echo "$USER"
> echo "$PWD"
> echo "$SHELL"
> echo "$PATH"



Shell-переменные и переменные окружения

В Bash можно создать обычную переменную:

> NAME="Alice"

Она доступна в текущем shell:

> echo "$NAME"

Но сама по себе такая переменная не становится переменной окружения.

Чтобы передать её дочерним процессам, используется export:

> export NAME="Alice"

Теперь дочерняя программа сможет получить эту переменную.

Например:

> export NAME="Alice"
> bash

В новом shell:

> echo "$NAME"

выведет:

Alice

Это связано с тем, что дочерние процессы обычно получают копию окружения родительского процесса.



Изменение и удаление переменных

Изменить переменную можно обычным присваиванием:

> NAME="Bob"

Удалить переменную:

> unset NAME



Переменная PATH

Одной из наиболее важных переменных окружения является:

PATH

Она содержит список каталогов, в которых shell ищет исполняемые программы.

Например:

> echo "$PATH"

может дать:

/usr/local/bin:/usr/bin:/bin

Каталоги разделяются символом :.

Когда пользователь вводит:

> python

shell ищет подходящий исполняемый файл в каталогах из PATH.

Это можно проверить с помощью:

> which python

/usr/bin/python

А посмотреть, как shell интерпретирует команду, можно через:

> type python



Изменение PATH

К переменной PATH можно добавить новый каталог:

> export PATH="$HOME/bin:$PATH"

Теперь при поиске программ shell будет сначала проверять:

/home/alice/bin

а затем остальные каталоги из старого PATH.



При изменении PATH обычно нужно сохранять старое значение:

> export PATH="$HOME/bin:$PATH"

Если вместо этого полностью заменить PATH, можно случайно сделать обычные команды недоступными.





Переменные окружения - это способ передавать информацию и настройки от процесса к его дочерним процессам.

Особенно важно понимать:

переменная shell
       ↓
     export
       ↓
переменная окружения
       ↓
дочерний процесс

А PATH стоит запомнить отдельно: именно он позволяет shell находить программы по их имени.
