Типы файлов и архивы

В Linux файл - не обязательно текстовый документ. В файловой системе встречаются обычные файлы, каталоги, символические ссылки и специальные объекты.

При работе с CTF часто нельзя заранее определить тип файла только по его имени или расширению. Поэтому важно уметь самостоятельно исследовать неизвестные файлы. Отдельный полезный навык - работа с архивами: задания могут содержать несколько уровней вложенных архивов, которые необходимо последовательно определить и распаковать.

Типы файлов

В выводе ls -l первый символ показывает тип объекта.

Например:

> ls -l

может вывести:

-rw-r--r--  notes.txt
drwxr-xr-x  documents
lrwxrwxrwx  config -> /etc/config

Здесь:

-   обычный файл
d   каталог
l   символическая ссылка

Обычный файл может содержать практически любые данные: текст, изображение, архив, бинарные данные, исполняемую программу

Поэтому расширение имени не следует считать надёжным способом определения типа файла. Например, файл secret.txt совсем не обязательно действительно является текстовым файлом.



Определение типов с помощью утилиты file

Для определения содержимого файла используется команда file:

> file secret.txt

Например:

secret.txt: PNG image data, 800 x 600

Несмотря на расширение .txt, file определил объект как изображение.

Таким образом, при встрече с неизвестным файлом полезно начать с команды:

> file filename



Архивы и сжатие

Архив - это файл, содержащий несколько других файлов и/или директорий.

Сжатие уменьшает объем данных. Эти операции не обязательно совпадают: архив может содержать несколько файлов и при этом не использовать сжатие, а сжатый файл может содержать только один объект.

На практике, однако, чаще используются комбинации этих подходов.



tar

tar — один из основных инструментов для создания и распаковки архивов в Linux.

Создать архив:

> tar -cf archive.tar file1.txt file2.txt

Распаковать:

> tar -xf archive.tar

Посмотреть содержимое архива без распаковки:

> tar -tf archive.tar

Часто встречается формат .tar.gz (сжатый):

> tar -czf archive.tar.gz project/

Распаковать его:

> tar -xzvf archive.tar.gz

основные параметры:

c   создать архив
x   распаковать
t   показать содержимое
f   указать имя файла архива
z   использовать gzip
v   вывести распакуемые файлы



gzip и gunzip

gzip используется для сжатия отдельных файлов:

> gzip file.txt

После этого обычно появляется:

file.txt.gz

Распаковать его можно:

> gunzip file.txt.gz

Важно помнить: gzip - это сжатие, а не полноценный архив нескольких файлов.

Для набора файлов часто используется связка tar+gzip, то есть архивы вида

archive.tar.gz



ZIP

Формат ZIP очень распространён и в Linux, и в других операционных системах.

Создать архив:

> zip archive.zip file1.txt file2.txt

Распаковать:

> unzip archive.zip

Посмотреть содержимое:

> unzip -l archive.zip
