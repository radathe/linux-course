# Просмотр содержимого файлов и поиск информации

Во время работы с Linux недостаточно уметь находить файлы. Нужно уметь быстро определить, что находится внутри файла, обработать полученные данные и найти среди них нужную информацию. В реальных задачах файл может содержать несколько строк, тысячи записей или вообще оказаться бинарным объектом, поэтому для разных ситуаций используются разные инструменты.

Отдельно стоит различать поиск информации внутри файлов и поиск самих файлов и других объектов файловой системы. В первом случае нас интересует содержимое объектов, например строка с определённым словом. Во втором — местоположение объекта, его имя, размер, тип, права доступа и другие свойства.



## Вывод содержимого файлов

Самый простой способ увидеть содрежимое текстового файла из терминала - вывести его командой `cat`:
```
$ cat file.txt
```
cat удобна для небольших файлов, когда содержимое помещается на экран. Для файлов, занимающих больше экрана терминала, лучше и удобнее использовать команду less:
```
$ less file.txt
```
less позволяет просматривать файл постранично. Для перемещения можно использовать стрелки или клавиши PageUp и PageDown, а выйти из режима просмотра можно, нажав q.



## Начало и конец файла

Иногда просматривать весь файл не требуется. Например, нужно узнать, что находится в первых или последних строках.

Команда head показывает начало файла:
```
$ head file.txt
```
По умолчанию выводятся первые 10 строк, но их количество можно указать явно:
```
$ head -n 20 file.txt
```
Команда tail работает аналогично, но показывает конец файла:
```
$ tail file.txt
```
или:
```
tail -n 20 file.txt
```
Например:
```
$ tail -n 3 log.txt
[INFO] User connected
[INFO] Data received
[INFO] Connection closed
```
Эти команды особенно полезны при работе с журналами и большими текстовыми файлами.



Просмотр количества строк и других характеристик

Для получения краткой информации о размере текстового содержимого используется wc:
```
$ wc file.txt
```
Пример:
```
$ wc file.txt
  25  137  824 file.txt
```
Здесь показаны:
```
25   — количество строк
137  — количество слов
824  — количество байт
```
Можно запросить только один показатель:
```
$ wc -l file.txt    # количество строк
$ wc -w file.txt    # количество слов 
$ wc -c file.txt    # количество байт
```


В CTF wc -l удобно использовать, чтобы быстро понять, насколько большой набор данных перед вами:
```
wc -l data.txt
```


Нумерация строк

Иногда при анализе файла важно знать номер строки. Для этого можно использовать nl:
```
nl file.txt
```
Пример:
```
     1  username=alice
     2  username=bob
     3  password=12345
```
Нумерация особенно полезна, когда нужно указать или повторно найти конкретное место в большом файле.



Обработка текстовых данных

Linux предоставляет большое количество небольших команд, предназначенных для обработки текста. Их главное преимущество проявляется тогда, когда команды соединяются друг с другом с помощью конвейера (пайпа) |.



В английском языке символ | называется pipeline, или, что более распространено, просто pipe. В русском языке нет действительно хорошего перевода этого слова в таком контексте. Официальным переводом является слово конвейер, но используется в этом ключе оно очень редко. Гораздо более распространена простая транслитерация - пайп.

| передаёт вывод команды слева от него на ввод команде справа. Давайте посмотрим, как это работает, а заодно узнаем несколько новых команд.

Для начала, команды:



Сортировка - sort

Команда sort сортирует строки в алфавитном порядке (по умолчанию).



Удаление повторяющихся строк - uniq

Команда uniq удаляет соседние одинаковые строки. Так как она работает только с последовательными одинаковыми строками, её часто используют вместе с sort:

$ sort file.txt | uniq

Именно так и работает пайп, он же конвейер. А такая последвательность команд позволяет легко получить набор уникальных значений независимо от их исходного порядка.





Подсчёт повторений

У uniq есть параметр -c, который позволяет посчитать количество одинаковых строк:

sort file.txt | uniq -c

Это уже позволяет не только очищать данные, но и анализировать их.



Выбор отдельных столбцов — cut

Если данные записаны в определённом формате, иногда нужно взять только одну их часть.

Например, имеем файл:

alice:1001:student
bob:1002:admin
charlie:1003:student

Если нужно получить только имена, можно использовать cut:

$ cut -d ':' -f 1 users.txt
alice
bob
charlie

Здесь:

-d ':'   — символ-разделитель
-f 1     — взять первое поле

Можно получить другое поле:

$ cut -d ':' -f 2 users.txt
1001
1002
1003



Если вы продолжите работать с Linux, то с пайпом вам придется встречаться очень часто. Далее я покажу более интересные и вполне реальные примеры его применения, а пока перейдем к следующей теме.



Поиск информации в файлах

Очень часто в CTF известно не имя нужного файла, а только фрагмент информации, который в нём содержится.

Например, мы знаем, что где-то есть слово:

password

В таком случае просматривать файлы вручную неудобно. Для поиска текста используется команда grep.

Самый простой пример:

$ grep "password" file.txt

Если файл содержит:

username=alice
password=12345
username=bob

результат будет:

password=12345

То есть grep выводит строки, в которых найдено указанное значение.



Вот некоторые флаги команды grep, которые могут вам понадобиться:





-i - поиск без учета регистра



-n - вывести номер строки, где найдено совпдение



-E - поиск по нескольким значениям: grep -E "password|secret|flag" file.txt. Будут выведены строки, содержащие хотя бы одно из значений

Другие флаги вы можете найти, почитав документацию или меню помощи команды.



Поиск во всех вложенных файлах

Если нужная информация может находиться не в одном файле, а во всей директории, используется рекурсивный поиск:

$ grep -R "flag" .

Здесь:

-R     - искать рекурсивно, включая вложенные каталоги
.      - начать поиск с текущего каталога

Например:

$ grep -R "password" .

может дать:

./config.txt:password=12345
./backup/users.txt:password=admin
./old/data.txt:temporary_password=abc

Теперь мы знаем не только найденную строку, но и файл, в котором она находится.

Например, если на CTF вам дали целую директорию с неизвестным содержимым и известно ключевое слово, то

$ grep -R "flag" .

- один из первых вариантов, который стоит попробовать.





grep очень часто встречается в последовательности команд, соединенных пайплайном. Разберем конкретный пример:

$ grep "Failed password" /var/log/auth.log | awk '{print $(NF-3)}' | sort | uniq -c | sort -rn | head -10

Задача здесь следующая: найти в логах самые частые IP-адреса, с которых были неудачные попытки входа. Для этого мы анализируем файл auth.log - логи аунтификаций. Первым действием ищем строки с фразой "Failed password" - так помечены неудачные попытки аутентификации. Затем перенаправляем вывод grep в команду awk, которая здесь вытаскивает из строки IP-адрес. (Механизм работы утилиты awk здесь разбирать будет долго и сложно для текущего уровня курса, но если вам интересно, вы можете найти информацию самостоятельно). Следующие два действия - связка sort и uniq, которую мы уже разбирали ранее: sort сортирует вывод, а uniq -c считает, сколько раз встретился каждый IP-адрес. Затем sort -rn сортирует вывод по убыванию, чтобы самые частые адреса были сверху, после чего head -10 выводит 10 самых частых адресов, с которых были зафиксированы неудачные попытки аутентификации.



Перенаправление ошибок

При рекурсивном поиске по большой части системы могут появляться сообщения вроде:

grep: ./some_directory/file: Permission denied

Они выводятся в стандартный поток ошибок. Его можно перенаправить, например, в /dev/null:

$ grep -R "flag" / 2>/dev/null

Здесь:

/             - искать от корня файловой системы
2>/dev/null   - скрыть сообщения об ошибках

Это позволяет оставить на экране только полезные результаты поиска.



Поиск информации в файловой системе

Иногда нам неизвестно, в каком месте находится нужный файл. Мы можем знать только его имя, тип, размер, владельца или другие свойства.

Для такого поиска используется команда find.

Простейший вариант:

find .

Он выведет объекты, начиная с текущего каталога.

Например:

.
./file.txt
./notes
./notes/passwords.txt
./images
./images/photo.png

Это уже позволяет посмотреть структуру каталога без ручного перехода в каждую директорию.



Поиск по имени

Найти файл с конкретным именем:

$ find . -name "secret.txt"

Например:

./backup/secret.txt

Поиск без учёта регистра:

$ find . -iname "secret.txt"

Такой поиск найдёт:

secret.txt
Secret.txt
SECRET.TXT



Поиск по типу

Можно ограничить поиск определённым типом объекта.

Обычные файлы:

$ find . -type f

Директории:

$ find . -type d

Символические ссылки:

$ find . -type l

Например:

find . -type f -name "*.txt"

найдёт обычные файлы с расширением .txt.



Поиск по размеру

find умеет искать файлы по размеру.

Например, файлы больше 1 мегабайта:

$ find . -type f -size +1M

Файлы меньше 10 килобайт:

$ find . -type f -size -10k

Это бывает полезно, если условие CTF сообщает размер объекта или нам нужно выделить среди большого количества файлов особенно большие или маленькие.



Существуют и другие критерии поиска с помощью утилиты find. Вы можете узнать их из документации или меню помощи find (find --help).
