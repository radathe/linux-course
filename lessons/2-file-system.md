# Файловая система Linux
Файловая система -- это способ организации данных на диске. В Linux практически всё, с чем работает пользователь и программы, представляется в виде файлов или объектов, доступных через файловую систему. Это могут быть обычные файлы с текстом или изображениями, каталоги, устройства, специальные системные файлы и символические ссылки. 
> Интересный факт: Linux относится к Unix-подобным операционным системам (что означает, что Linux похож по своей структуре на операционные системы семейтва Unix --
предшествнников современных ОС), а следовательно, подчиняется философии Unix -- набору культурных норм и подходов к написанию ПО. Одна из концепций философии Unix -- "всё есть файл". Согласно ей, для доступа ко всем ресурсам ОС используется единый интерфейс файловой системы. Если проще, ОС видит как файл всё: директорию (папку), сокет (сетевое соединение), собственно, сам файл. Это позволяет системе работать с железом, сетевыми соединениями и процессами через стандартные операции чтения и записи вместо того, чтобы придумывать новые.

## Иерархия файлов
В Linux используется единая иерархическая структура каталогов. В отличие от Windows, где диски обычно обозначаются буквами (C:, D: и т. д.), файловая система Linux имеет одну корневую точку, обозначаемую /. От неё начинаются все остальные каталоги и файлы. 
### Корневая директория
Самый верхний уровень файловой системы Linux называется ___корневой директорией___ и обозначается символом `/`.

Это выглядит примерно так:
```
/
├── home/ 
├── etc/
├── tmp/ 
├── usr/ 
├── var/ 
└── ...
```
Все файлы или директории находятся внутри этой иерархии. Например, домашняя директория пользователя может находиться по пути:
```
/home/alice
```
а некоторый файл конфигурации:
```
/etc/example.conf
```
Здесь первый `/` -- корень файловой системы, остальные же используются для разделения в записи пути. Символ `/` также нередко пишется в конце названия директории, чтобы показать, что это директория и следом за ней в файловой системе может быть что-то еще. 

Чтобы посмотреть содержимое текущей директории, используется команда `ls`:
```
$ ls
```
или более подробный вариант:
```
$ ls -l
```
### Домашняя директория
___Домашняя директория___ также уже упоминалась ранее, однако остановимся поподробнее и на ней. Домашняя директория своя у каждого пользователя, и зачастую путь до неё, например, `/home/alice`, сокращается до `~`. В зависимости от текущего пользователя система сама подставляет путь до его домашнего каталога.
> Примечание: каталог -- просто синоним слову "директория". В литературе и обсуждениях используются оба варианта, так что оба их полезно знать.

## Пути в файловой системе. Скрытые файлы
Путь — это последовательность каталогов, которая показывает, где находится нужный файл или каталог.
Существуют два основных вида путей -- абсолютные и относительные.
### Абсолютный путь
Абсолютный путь начинается с `/` и задаёт положение объекта относительно корня файловой системы.
Например:
```
/home/alice/Documents/report.txt
```
Такой путь однозначно указывает на конкретный объект независимо от того, в каком каталоге сейчас находится пользователь.

Путь до текущей директории выводит команда, название которой является абривиатурой от "print working directory":
```
$ pwd
```
Пример:
```
$ pwd
/home/alice
```
Теперь можно перейти в каталог Documents:
```
$ cd /home/alice/Documents
```
### Относительный путь
Относительный путь задаётся относительно текущего каталога. 
Например, если пользователь сейчас находится здесь: 
```
/home/alice
```
то файл `/home/alice/notes.txt` можно обозначить просто `notes.txt`,
а директорию `/home/alice/Documents` просто `Documents`. 

Соответственно, перейти в нее можно, просто выполнив команду:
```
$ cd Documents
```
### Обозначения `.` и `..`
Текущий каталог обозначается:
```
.
```
Родительский каталог, то есть каталог уровнем выше:
```
..
```
Например:
```
$ cd ..
```
переместит пользователя на один уровень вверх.

Если текущий каталог:
```
/home/alice/Documents
```
то команда:
```
$ cd ..
```
переместит пользователя в:
```
/home/alice 
```
Можно использовать и более сложные пути:
```
$ cd ../Downloads
```
Здесь сначала происходит переход в родительский каталог, после чего — в Downloads.
### Скрытые файлы
В Linux файл считается скрытым, если его имя начинается с точки:
```
.config
.bashrc
.secret
```
Например
```
$ ls
```
может не показать такие файлы.

Чтобы увидеть их, используется
```
ls -a 
```
(-a сокращенно от all -- все).
Пример:
```
$ ls -a
.
..
.bashrc
.config
Documents
notes.txt
```
Обратите внимание, что `.` и `..` также отображаются. Это специальные обозначения текущего и родительского каталогов, а не обычные скрытые файлы.

При необходимости можно совместить просмотр скрытых файлов с подробной информацией:
```
$ ls -la
```
## Основные системные директории
Linux использует стандартную структуру каталогов. Конкретный набор каталогов и их содержимое могут немного отличаться между дистрибутивами, однако назначение основных директорий обычно остаётся похожим.

### `/home`

Домашние каталоги обычных пользователей:
```
/home/alice
/home/bob
```

### `/root`

Домашний каталог суперпользователя root.

Он отличается от `/`, несмотря на похожее название:
`/` -- корень всей файловой системы, а `/root` -- домашний каталог пользователя root.

### `/etc`

Содержит системные конфигурационные файлы.

Например:
```
/etc/passwd
/etc/hosts
/etc/fstab
```
В задачах по информационной безопасности этот каталог встречается довольно часто, поскольку здесь находится множество настроек системы и программ.

### `/tmp`

Каталог для временных файлов.

Многие программы используют его для хранения временных данных.
Особенность `/tmp` в том, что его содержимое обычно не предназначено для долговременного хранения.


### `/var`

Содержит данные, которые изменяются во время работы системы.

Например, здесь часто располагаются журналы:
```
/var/log
```
и другие данные, которые создаются или изменяются работающими программами.

### `/usr`

Содержит значительную часть пользовательских программ, библиотек и других данных, устанавливаемых системой, например:
```
/usr/bin
/usr/lib
/usr/share
```

### `/bin`

Исторически здесь находились основные исполняемые программы системы, например, `ls` или `mv`.
Во многих современных дистрибутивах `/bin` является символической ссылкой или иным образом объединён с `/usr/bin`.

Поэтому в учебных материалах важно запомнить прежде всего идею:

`/bin` связан с базовыми исполняемыми программами системы.

### `/sbin`

Содержит системные программы, многие из которых предназначены прежде всего для администрирования.

### `/dev`

Содержит специальные файлы, через которые программы могут взаимодействовать с устройствами.

Например:
```
/dev/null
```
Это уже не обычные файлы в привычном смысле.

Например:
```
$ echo "Hello" > /dev/null
```
Выведенный текст будет передан в /dev/null и фактически отброшен.

### `/proc`

Виртуальная файловая система, предоставляющая информацию о работающей системе и процессах.

Например:
```
/proc/cpuinfo
/proc/meminfo
```
Содержимое этих файлов формируется системой и может изменяться во время работы компьютера.

Глубоко разбирать `/proc` на этом этапе не требуется, но важно знать, что файловая система Linux содержит не только обычные файлы на диске.

> Важно:

> Не все объекты, которые выглядят как файлы, обязательно являются обычными файлами, сохранёнными на диске. Linux использует единый интерфейс для работы со множеством разных объектов.
## Основные операции с файлами
Для работы с файловой системой используется набор стандартных команд.

Просмотр содержимого каталога -- `ls`

Подробный вывод (включает в себя права доступа к файлу, владельца файла, время его последнего изменения и другую информацию):
```
$ ls -l
```
Включая скрытые файлы:
```
ls -la
```
Переход между каталогами -- `cd`
```
$ cd Documents
```
Переход в родительский каталог:
```
$ cd ..
```
Переход в домашний каталог:
```
$ cd ~
```
Переход по абсолютному пути:
```
$ cd /etc
```
Определение текущего каталога -- `pwd`
```
$ pwd
```
Пример:
```
$ pwd
/home/alice/Documents
```
Создание каталога -- `mkdir`
```
$ mkdir test
```
Можно создать несколько уровней каталогов сразу:
```
$ mkdir -p project/src/include
```
Создание пустого файла -- `touch`
```
$ touch notes.txt
```

`touch` также может использоваться для изменения времени доступа или модификации существующего файла.

Копирование -- `cp`

Скопировать файл:
```
$ cp notes.txt backup.txt
```
Скопировать файл в другой каталог:
```
$ cp notes.txt Documents/
```
Для копирования каталогов используется параметр:
```
$ cp -r project project_backup
```
Здесь -r означает рекурсивное копирование каталога вместе с его содержимым.

Перемещение и переименование -- `mv`

Переместить файл:
```
$ mv notes.txt Documents/
```
Переименовать файл:
```
$ mv notes.txt notes_old.txt
```
С точки зрения команды `mv` эти операции очень похожи: во втором случае объект просто перемещается в том же каталоге под другим именем.

Удаление -- `rm`

Удалить файл:
```
$ rm notes.txt
```
Удалить каталог с содержимым:
```
$ rm -r project
```

> Предупреждение

> rm обычно не отправляет файлы в «Корзину». Удаление может быть необратимым.
Особенно опасны команды с -r и -f. Перед выполнением такой команды всегда полезно проверить, где именно вы находитесь:
```
$ pwd
```
и что именно собираетесь удалить:
```
$ ls
```
### Просмотр содержимого файла

Для небольших текстовых файлов:
```
$ cat notes.txt
```
Для больших файлов удобнее:
```
$ less notes.txt
```
Первые строки:
```
$ head notes.txt
```
Последние строки:
```
$ tail notes.txt
```
## Символические ссылки
Символическая ссылка (symbolic link, symlink) — это специальный объект файловой системы, который содержит путь к другому файлу или каталогу.

Можно представить её как «указатель» или «ярлык»:
```
link.txt  --->  original.txt
```
Если обратиться к `link.txt`, операционная система перейдёт к объекту, на который он указывает.

Создать символическую ссылку можно с помощью:
```
$ ln -s original.txt link.txt
```
После этого `ls -l` может показать:
```
-rw-r--r--  original.txt
lrwxrwxrwx  link.txt -> original.txt
```
Стрелка здесь показывает, куда направлена ссылка. 

Символическая ссылка может указывать на директорию:
```
$ ln -s /home/alice/Documents docs
```
Теперь
```
$ cd docs
```
позволит перейти в каталог
```
/home/alice/Documents
```

### Что произойдет при удалении исходного файла?
Рассмотрим пример.
```
original.txt 
link.txt -> original.txt
```
Если удалить исходный файл:
```
$ rm original.txt
```  
сама ссылка останется, но теперь будет указывать на несуществующий файл. Такого следует избегать. 

## Практика
Если эта информация нова для вас, обязательно выполните практическое задание к этой теме. Также не брезгуйте документацией: пробуйте писать что-то вроде:
```
$ <command> --help   # краткая справочная информация о команде: её использование, флаги и аргументы
```
или
```
$ man <command>      # мануал на команду, фактически, встроенная документация 
```
чтобы узнать больше. 

Скорее всего, количество команд кажется вам сложным для запоминания, но суть в том, чтобы учиться на практике. Далее по курсу, который будет относиться уже не к Linux, вам придется использовать многие из этих команд. Сейчас вам главное понять, какие команды бывают и как узнавать о них больше. 

Вам также придется работать и с файловой системой. Вы научитесь и этому в процессе практики. Помните: вам не нужно знать всего вразу, главное -- иметь примерное понимание и готовность учиться. Удачи!
