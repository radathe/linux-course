Bash

Bash (Bourne Again Shell) — командная оболочка, широко используемая в Linux. Но давайте сначала разберемся, то же такое оболочка.



Оболочка (shell)

Оболочка (shell) - это программа-посредник между пользователем и ядром Linux. Она принимает команды, которые вы вводите, разбирает их, интерпретирует и запускает нужные программы. Например, когда вы пишете ls, оболочка находит исполняемый файл ls, запускает его и показывает результат в терминале. Без оболочки взаимодействовать с системой можно, но гораздо сложнее: она берёт на себя ввод команд, аргументы, переменные, перенаправления и конвейеры.

Важно различать терминал и оболочку. Терминал - это окно или программа (например, GNOME Terminal, Konsole, xterm), через которую вы вводите текст и видите вывод. Оболочка - это то, что работает внутри терминала и обрабатывает команды. Самые известные оболочки: bash (чаще всего по умолчанию), zsh, fish, sh.

Все запускаемые пользовательские программы в Linux запускаются через shell.

Чтобы узнать, какая оболочка сейчас используется, можно запустить команду:

> echo $SHELL



Вернемся к Bash. До этого мы уже использовали Bash, даже если отдельно его не рассматривали: команды cd, ls, grep, конвейеры |, перенаправления > и переменные вроде $HOME обрабатываются shell. Теперь рассмотрим основные возможности Bash, которые особенно полезны при автоматизации CTF-задач.



Команды и аргументы

Обычная команда в Bash состоит из имени программы и, при необходимости, аргументов:

> ls -la /home

Здесь:

ls       программа
-la      параметры
/home    аргумент

Другой пример:

> grep "password" file.txt

Здесь grep получает два аргумента:

"password"
file.txt

Чтобы получить дополнительную информацию о команде, можно использовать:

> command --help или > man command



Переменные

Bash позволяет хранить данные в переменных.

Создание переменной:

> name="Alice"

Получение значения:

> echo "$name"

Результат:

Alice

Важно: при присваивании пробелы вокруг = не ставятся.

В Bash переменная подставляется с помощью $:

> echo "$name"

Можно создавать и числовые переменные:

> count=10
> echo "$count"



Переменные окружения

Некоторые переменные Bash получает из окружения процесса.

Например:

> echo "$USER"
> echo "$HOME"
> echo "$PWD"
> echo "$PATH"

Посмотреть все переменные окружения можно:

> env

Создать переменную окружения (временно) позволяет export:

> export NAME="Alice"



Подстановка команд

Bash позволяет использовать результат одной команды как часть другой.

Современный и рекомендуемый синтаксис:

current_dir=$(pwd)
echo "$current_dir"

Рекомендуемые ограничения ресурсов и отключение сети (нужен только
localhost):

> docker run --rm -it \
    --memory=256m --cpus=0.5 \
    --network=none \
    linux-ctf/t01

Здесь:

$(pwd)

заменяется результатом выполнения pwd.

Например:

echo "You are in $(pwd)"

может вывести:

You are in /home/alice/ctf

Это позволяет строить более сложные команды и скрипты.



Условия

В Bash можно выполнять разные действия в зависимости от условия.

Например:

if [ -f "secret.txt" ]; then
    echo "File exists"
else
    echo "File not found"
fi

Здесь:

-f - проверить, существует ли обычный файл

Конструкция:

if [ условие ]; then
    ...
fi

встречается в Bash очень часто. Важно привыкнуть к тому, что перед [ и после ] в таком синтаксисе стоят пробелы.



Цикл for

Циклы позволяют автоматически повторять действия.

Самый простой пример:

for i in 1 2 3 4 5
do
    echo "$i"
done

Результат:

1
2
3
4
5

Можно использовать диапазон:

for i in {1..10}
do
    echo "$i"
done

Это особенно полезно в CTF, когда требуется проверить множество вариантов.

Например:

for file in *
do
    echo "$file"
done

Этот цикл перебирает объекты текущей директории.



Цикл while

Другой распространённый цикл:

count=1

while [ "$count" -le 5 ]
do
    echo "$count"
    count=$((count + 1))
done

Результат:

1
2
3
4
5

Здесь появляется простая арифметика:

count=$((count + 1))

Подробное программирование на Bash для нашего курса не требуется; достаточно понимать принцип циклов и уметь использовать их в небольших скриптах.



Создание Bash-скрипта

Скрипт - это обычный текстовый файл, содержащий команды Bash.

Например, info.sh:

#!/bin/bash

> echo "Current user: $USER"
> echo "Current directory: $PWD"
> echo "Files:"
> ls -la

Первая строка:

#!/bin/bash

называется shebang. Она указывает, какой интерпретатор должен использоваться для выполнения файла.

Чтобы запускать скрипт напрямую:

> chmod +x info.sh

После этого:

> ./info.sh



Аргументы командной строки

Bash-скрипту можно передавать аргументы:

> ./script.sh file.txt

Внутри скрипта:

$1

содержит первый аргумент:

file.txt

Например:

#!/bin/bash

echo "File: $1"

Запуск:

> ./script.sh secret.txt

Результат:

File: secret.txt

Другие специальные переменные:

$0   имя самого скрипта
$1   первый аргумент
$2   второй аргумент
$@   все аргументы
$#   количество аргументов



Возвращаемый код

Каждая завершившаяся команда возвращает числовой код завершения.

Обычно:

0 → успешное выполнение
ненулевое значение → ошибка или другой результат

Последний код можно посмотреть:

> echo $?

Например:

> ls file.txt
> echo $?

Если файл существует:

0

Если команда завершилась ошибкой, можно получить другое значение.



Это используется в условиях:

if ls file.txt > /dev/null 2>&1; then
    echo "Success"
else
    echo "Error"
fi



Bash и конвейеры (пайпы)

Bash-скрипты особенно хорошо подходят для соединения небольших программ.

Например:

grep "flag" logfile.txt | sort | uniq

или:

find . -type f | wc -l

Здесь Bash-скрипт организует передачу данных между программами.

Можно построить небольшой скрипт:

#!/bin/bash

for file in *.txt
do
    echo "=== $file ==="
    grep -i "flag" "$file"
done

Такой скрипт автоматически проверит все .txt-файлы в текущей директории.



Пример автоматизации

Предположим, есть файлы:

file1.txt
file2.txt
file3.txt
...
file100.txt

и в одном из них находится нужная строка.

Вместо ручного открытия каждого файла можно использовать:

for file in *.txt
do
    if grep -qi "flag" "$file"
    then
        echo "Found in: $file"
    fi
done

Это простой пример того, зачем нужен Bash в CTF:



он превращает повторяющуюся последовательность ручных действий в одну автоматическую процедуру.
